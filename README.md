# xixi-s-solidity-learning
0x
1、业务背景
开发staking 产品
2、目标用户
小额散户用户：持有零散主网代币，无大额本金，追求低门槛 + 资产流动性；
3、核心使用场景
主场景 1：用户连接钱包→输入质押数量→确认交易→到账质押凭证；
主场景 2：用户解除质押→提交赎回申请→等待解锁→本金及奖励返还至用户钱包；
异常场景：链上 Gas 异常交易失败、赎回排队流动性不足、再质押触发罚没 Slashing、抵押类质押抵押率跌破清算线。
4、功能需求
4.1质押存入页面
钱包连接：支持 MetaMask、Rabby 等主流 Web3 钱包；
数量输入：最小质押限额、最大质押限额；
合约授权 + 质押确认：先授权合约代付，再发起质押交易，上链成功自动发放质押凭证；
规则弹窗：展示赎回周期、手续费规则、罚没风险、交易风险提示。
4.2 我的持仓页面
持仓数据：原生本金估值、质押凭证数量、待结算未发放收益；
分层收益明细：底层链原生奖励、再质押奖励；
4.3 赎回提现页面
赎回数量输入：全额 / 部分赎回，实时提示排队周期、赎回手续费；
赎回队列展示：当前排队人数、预计到账区块时间；
到账记录：历史赎回上链记录。
4.4 平台质押页面
实时更新质押池ETH总数量；可以紧急暂停合约运行。
5、业务流程
用户授权代币→质押→更新质押池数量及用户质押数量
系统开始计算收益
用户可随时领取奖励
用户可随时解质押取回本金
用户解质押时自动结算未领奖励
更新质押池数量
