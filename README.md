# 开发小额staking 产品

## 目标用户及相关质押规则

### 目标用户
小额散户用户：持有零散主网代币，无大额本金，追求低门槛 + 资产流动性

### 核心使用场景
主场景 1：用户连接钱包→输入质押数量→确认交易→到账质押凭证
主场景 2：用户解除质押→提交赎回申请→等待解锁→本金及奖励返还至用户钱包
异常场景：链上 Gas 异常交易失败、赎回排队流动性不足、再质押触发罚没 Slashing、抵押类质押抵押率跌破清算线

## 业务流程
用户授权代币→质押（质押最小金额为0.1eth，且不能为0）→更新质押池数量及用户质押数量（设置单个地址最大质押额50Eth，质押池总质押额5000Eth）
系统开始计算收益
用户可随时领取奖励
按节点收益抽取手续费
用户可随时解质押取回本金
罚没计算：底层底层节点被以太坊罚没一定数量 ETH 时，整个质押池亏损等额 ETH，所有质押用户按自己份额占比同比例缩水本金及质押凭证
用户解质押时自动结算未领奖励（防重入，避免重复领取本金和奖励）
更新质押池数量

### 质押奖励规则
计息基准规则:按质押份额加权计息
用户质押本金占整个质押池总质押量的比例，瓜分全网每日/每区块产出奖励；质押凭证数量等价于份额占比，凭证越多分红越高
公式：用户当日奖励 = 当日总奖励 ×（用户质押份额 ÷ 质押池总份额）
计息起算时间质押交易上链成功即刻开始计息；不存在 T+1 延迟；中途追加质押，追加部分同步开始计息
